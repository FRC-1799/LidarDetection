# The Source Code for 1799LidarLib, A library to interface with and manage slamtec Lidar units, both generally and for FRC specific uses. 
 
This package is not currently stable enough to be on the main pip database. However the development version can be downloaded via `pip install -i https://test.pypi.org/simple/ 1799LidarLib`. While there are currently no dedicated pydocs, everything does have somewhat decent docstrings so check there for any questions.
